# 📦 HyperFrames — Локальная база компонентов (Offline Library)

Полный оффлайн-архив **236 компонентов** из официального каталога [HyperFrames Components](https://hyperframes.heygen.com/catalog/components/).
Каждый компонент содержит автономный HTML-сниппет, стили, анимации GSAP/CSS и все сопутствующие ассеты (шрифты, маски, текстуры).

## Быстрое использование в HTML-композициях
1. Откройте папку нужного компонента: `hyperframes/components/<имя>/`
2. Скопируйте HTML-разметку, `<style>` и `<script>` в вашу композицию `index.html`.
3. Переменные (`variables`) и ключевые точки (`syncPoints`) описаны в `registry-item.json` каждого компонента.
